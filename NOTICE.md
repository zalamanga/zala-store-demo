# Asal proyek

Proyek ini merupakan perapihan source lokal `sendiri/ZalaStore` yang berisi PHP, JavaScript, HTML, dan CSS. Source asal disimpan terpisah sebelum perubahan. Brief lama menyebut Laravel, Vue/React, MySQL, dan payment gateway; teknologi serta integrasi tersebut tidak ada pada aplikasi ini.

Gambar `public/assets/zalastore-products.png` disalin tanpa perubahan dari source lokal. Asal pembuat dan lisensi gambar tidak tercatat pada source yang diterima. Tidak ada atribusi pembuat atau lisensi baru yang diasumsikan untuk gambar maupun source lama.

Katalog, akun, dan pesanan untuk pengujian adalah data sintetis. Aplikasi membuat pesanan simulasi dan tidak memproses pembayaran atau menghubungi provider pembayaran.
